# What is AWS Secrets Manager?

AWS Secrets Manager is just a place to store your passwords, secrets, and API keys, and to let your AI agents safely retrieve them, knowing that your private information won't get leaked.

Since the lab already makes use of AWS, this is a good place to store this information in a secure way.

See [this writeup](docs/manuals/data_management/HOW_TO_GET_API_KEYS_AND_SECRETS.md) for how to make use of it.
