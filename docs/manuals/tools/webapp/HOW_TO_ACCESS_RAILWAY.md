# How to access Railway

We use Railway for deploying web servers. We have a lab account for Railway.

Steps:

1. Create a [free account with Railway](https://railway.com/account).
2. Message Mark in order to get added to the lab Railway workspace.
3. Add the [Railway MCP](https://docs.railway.com/ai/mcp-server) wherever you write code (ask ChatGPT/Claude/etc. how to link to your app of choice).
4. When deploying to Railway, point the AI agent to [this link, to deploy Railway via infrastructure-as-code](https://docs.railway.com/infrastructure-as-code).
