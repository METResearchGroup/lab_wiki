# Automated prompt-tuning

The best way to prompt-tune is to not have to manually prompt-tune yourself, but to use something else that can prompt-tune.

There are two ways to do this:

1. Basic: you can use optimizers online, like the OpenAI or Claude prompt optimizers. This works for most of these cases, especially if you just want to see how to make your prompt better.
2. Advanced: you can use `dspy` and GEPA or other optimizers to iteratively optimize your prompt. This is a pretty advanced technique, but if you really want to eke out the best performance from your prompt tuning (and you want to make sure that you couldn't have optimized your prompt any more than you already have), for example, if you really need an LLM to do well in a classification and you tried everything else, I'd suggest exploring this more advanced technique.
