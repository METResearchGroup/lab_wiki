# How do you run code on big data?

What happens if you're working with big data?

Here, we'll just define big data as "data that's too large to comfortably fit on your computer".

A problem which may be caused by big data is that trying to do any code on the big data eats up a lot of your computer's RAM or takes up a lot of time. You can see if it takes up a lot of RAM by either looking at the RAM usage on the Activity Monitor in your computer (if you have a Mac) or the equivalent for Windows. You can also notice this just in your everyday usage. If you are unable to open any other windows or tabs, or if other windows or tabs are noticeably slowed down because of code that you are running, then this means that the computer is using up too much RAM to run your code.

We'll discuss strategies for addressing this.
