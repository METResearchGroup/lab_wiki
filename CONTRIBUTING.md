# Contributing to the repo

Thank you so much for helping grow the lab's collective wiki!

This is a great place for us to collectively share knowledge and learn from each other.

A few guidelines as you're contributing to the repo:

## Please avoid AI-generated writing

Please avoid AI-generated writeups here as much as possible, and if something is AI-generated, please make it clear in the writeup.

We want this to be a wiki comprised of the lab's hard-earned personal wisdom, experiences and skills that they themselves can vouch for.

If it's something that Claude can already tell you, then we could just ask Claude!

Some caveats:

1. If you do use AI for writing, add a caveat or a note to the file. For example, in this file (https://github.com/METResearchGroup/lab_wiki/blob/main/docs/manuals/tools/bluesky/WHAT_DATA_IS_AVAILABLE_IN_BLUESKY.md) there's a caveat at the beginning on AI usage in the file.
2. Where AI is used (editing, research, etc), please verify the content.
3. Regardless of AI usage, please add your own commentary, wisdom, and experiences (which you have plenty of!)

## How to contribute

1. Clone the repo locally.
2. Checkout a new branch.
3. Make changes.
4. Git push to remote.
5. Open a PR.
6. Merge a PR.

We do it this way so that we can more easily attribute changes to a PR, so we know when changes were made to wiki docs. See this writeup (https://github.com/METResearchGroup/lab_wiki/blob/main/docs/manuals/tools/github/GITHUB_BASICS.md) for what a PR is.

## Final note

Thank you so much for contributing to the wiki! It's hard enough to do all of our jobs individually, but the more we can learn from each other, the easier all our lives are and the more we can focus on doing good research.
